# 마법공식 검색기

국내 전 종목(코스피·코스닥, 금융·유틸리티·스팩·우선주 제외)을 **마법공식 · 저PER · 저PBR · FCF 수익률** 중 고른 방법으로 순위를 매겨 폰 앱 화면에 보여 줍니다. 마법공식은 조엘 그린블라트 『주식시장을 이기는 작은 책』의 방법입니다. 종가매매(`jongga`)·오닐(`oneil`) 검색기와 같은 구조입니다.

- **앱 주소:** https://kyuiklee.github.io/magic/
- 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 처음 한 번 설정
1. Settings → Pages → Source를 **GitHub Actions**로
2. Settings → Secrets and variables → Actions → `DART_API_KEY` 등록 (오닐 앱과 같은 OpenDART 인증키). 마법공식은 재무 데이터가 꼭 필요합니다.
3. Actions → **마법공식 검색** → Run workflow (첫 실행은 6년치 재무·5년치 일봉 수집 때문에 15~30분 걸릴 수 있습니다)

평일 16:08(KST)에 자동 실행됩니다.

## 공식
| 방식 | 이익수익률 (쌈) | 자본수익률 (장사를 잘함) |
|---|---|---|
| 원형 | 영업이익(최근 4분기 합) ÷ (시가총액 + 부채총계) | 영업이익 ÷ (자산총계 − 유동부채) |
| 간편 (책 부록) | 순이익 ÷ 시가총액 (= 1/PER) | 순이익 ÷ 자산총계 (ROA) |

두 값을 각각 전 종목 순위로 바꿔 더하고, 합이 작은 순서로 보여 줍니다. 적자 종목은 제외합니다.

| 단일 지표 | 계산 | 제외 |
|---|---|---|
| 저PER | 시가총액 ÷ 지배주주 순이익(최근 4분기 합) | 적자 |
| 저PBR | 시가총액 ÷ 지배주주 자본(최근 분기) | 자본잠식, 적자 |
| FCF 수익률 | (영업활동현금흐름 − 유형·무형자산 취득, 최근 4분기 합) ÷ 시가총액 | FCF 마이너스 |
| 고ROE | 지배주주 순이익 ÷ 지배주주 자본 | 적자, 자본잠식 |
| 고ROA | 지배주주 순이익 ÷ 자산총계 | 적자 |
| 고배당 | 예상 배당수익률 = 직전 연도 주당배당금 ÷ 현재 주가 (국내: DART 배당에 관한 사항 보통주, 미국: 최근 4분기 배당금 지급 ÷ 주식 수) | 무배당 |

저PER·저PBR·FCF는 여러 개를 함께 골라 조합할 수 있습니다. 지표마다 순위를 매겨 더한 합이 작은 순서입니다(마법공식과 같은 방식). 백테스트는 시작 연도(처음부터·2022~2025)를 고를 수 있습니다.

FCF는 DART 주요계정에 없어 회사별 전체 재무제표(현금흐름표)를 따로 받습니다(`engine/cashflow.py`). 5년치 전체가 약 6만 건이라 한 번에 받을 수 없어서, 오늘 기준 FCF에 필요한 보고서부터 받고, 과거분은 실행마다 최대 45분(`CF_MINUTES`)씩 최신→과거 순으로 채웁니다(DART 하루 한도 약 2만 건). FCF 백테스트는 데이터가 60% 이상 채워진 달부터 시작합니다.

같은 응답에서 지배주주 순이익·자본도 뽑아 PER·PBR에 씁니다. 증권사·계열사를 연결로 잡는 지주회사(예: 다우데이타→키움증권)는 연결 순이익·자본 대부분이 다른 주주 몫이라 연결 전체로 계산하면 PER이 0.5배처럼 엉뚱하게 나오기 때문입니다. 지배주주 값이 아직 없는 과거 달은 연결 전체로 대신합니다.

앱에서 고르는 것: 공식, 시장(전체·코스피·코스닥), 시가총액 하한(500억~1조), 20일 평균 거래대금 하한, 종목 수(10~50), 백테스트 보유 기간(3·6·12개월), 매매 비용.

## 미국 시장
앱 위쪽 **국내/미국** 버튼으로 바꿉니다. 같은 공식(마법공식·저PER·저PBR·FCF·조합), 백테스트, 포트폴리오를 NYSE·나스닥 상장사(금융·부동산·유틸리티 섹터, 시총 1억 달러 미만 제외)에 적용합니다.
- 종목 목록: 나스닥 종목 목록 API (섹터·시가총액 포함)
- 재무: Yahoo Finance fundamentals-timeseries, 종목당 요청 1번에 연간 4년 + 최근 5분기. 손익·현금흐름은 최근 4분기 합, 4분기가 안 모이면 직전 연간 값. 재무가 달러가 아닌 회사(일부 해외 기업 ADR)는 제외
- 공시 시점은 분기 말 + 45일, 회계연도 말 + 80일로 가정 → 미국 백테스트는 2023년 무렵부터
- 시세: yfinance (지수 S&P500·나스닥 종합). 시가총액 = 재무의 발행주식수 × 종가 (주식분할 보정)
- SEC EDGAR는 GitHub Actions 서버의 접속을 막아서(403) 쓰지 않습니다
- `engine/us.py` → `site/data/us.json`. 미국 단계가 실패해도 국내 결과는 배포되고, 미국은 지난번 결과를 씁니다

## 해자·기업 유형 분석
순위에서 종목을 펼치면 아래 분석이 나옵니다 (모닝스타 공식 등급이 아니라 같은 근거를 숫자로 계산한 추정).
- 경제적 해자: 최근 몇 년 세후 ROIC(영업이익×(1−세율) ÷ (자산−유동부채))가 자본비용(약 8%)을 꾸준히 넘는지, 영업이익률 안정성, 이익의 현금 전환(FCF ÷ 순이익), ROIC 추세 → 넓은 해자/좁은 해자/해자 없음 추정. 해자 원천(전환비용·네트워크 효과·무형자산·효율적 규모·원가 우위)은 업종으로 추정. 미국 종목은 모닝스타 페이지 링크
- 순위 탭 종목 범위의 **경제적 해자** 필터(무관 · 좁은 해자 이상 · 넓은 해자만). 백테스트에서는 그 달까지 공시된 재무로만 등급을 다시 계산합니다. 등급에 최소 3년 재무가 필요해서, 해자 필터를 켜면 백테스트 시작이 국내는 2023년 중반, 미국은 2025년 초로 늦어집니다. 원자재·해운·정유·주택건설처럼 가격이 이익을 좌우하는 업종은 ROIC가 5년 넘게 10% 이상이어야 좁은 해자로 봅니다
- 기업 유형: 턴어라운드, 고성장, 지속 상승형, 해자 강한 기업, 대형 우량주, 경기순환형, 자산주, 저성장 안정형 (피터 린치 분류 기반, 여러 개 동시 가능)

## 내 전략
순위·백테스트에서 고른 조건(스크리닝 방법, 시장, 시총, 거래대금, 종목 수, 보유 기간)을 이름 붙여 저장합니다. 매일 갱신된 데이터로 오늘 종목, 이번 달 새로 들어온 종목, 백테스트 성과(연 수익·최대 낙폭·건별 승률·중앙값 점검)를 다시 계산합니다. "이 전략으로 순위 보기"로 조건을 불러오고, 종목을 한 번에 포트폴리오에 담을 수 있습니다.

추천 전략 2개가 기본으로 들어 있습니다 (2026-10 기준 데이터로 조건 수천 개를 시험해, 종목 수·시총·거래대금을 조금 바꿔도 결과가 유지되는 조건):
- 국내: 저PER+저PBR · 코스피 · 시총 1조↑ · 거래대금 5억↑ · 20종목 · 1년 보유
- 미국: 저PER+저PBR · NYSE · 시총 $1B↑ · 거래대금 $5M↑ · 20종목 · 1년 보유

## 내 포트폴리오
순위 탭에서 종목을 눌러 **포트폴리오에 담기**(또는 목록 전체를 투자금 기준 주수로 한 번에 담기). 매수일·매수가·수량을 고쳐 두면 현재 수익률, 같은 기간 코스피, 교체 예정일(매수일 + 보유 기간), 지금 순위(순위 밖이면 표시)를 보여 줍니다. 매도 기록을 남기면 실현 손익이 쌓입니다. 이 기기 브라우저에만 저장되므로 백업 글자로 옮기거나 보관하세요.

## 백테스트
보유 기간은 1~36개월 슬라이더로 정합니다.
- **분할 운용**: 자금을 보유 개월 수만큼 나눠 매달 한 몫씩 그달 상위 종목으로 같은 금액 교체 (책의 분할 매수 방식). 월말 종가 기준.
- **시작 달별 결과**: 아무 달에 시작해 1년(또는 3·6개월) 보유했을 때 수익 분포, 지수보다 나은 비율, 연 15% 이상 비율
- **종목 한 건씩**: 승률·중앙값·평균 (승률 51%↑, 중앙값 플러스 점검)

## 구성
- `engine/data.py` — 종목 목록(+KRX 업종)·일봉 수집 (네이버 차트 → FinanceDataReader → pykrx)
- `engine/fund.py` — OpenDART 영업이익·순이익 TTM, 자산·부채 (공시일 기준 시계열)
- `engine/us.py` — 미국: Yahoo 재무·시세 + 나스닥 종목 목록 → `us.json`
- `engine/dividends.py` — 국내: DART 배당에 관한 사항 → 연도별 보통주 DPS (회사당 2번 요청으로 6년)
- `engine/cashflow.py` — OpenDART 현금흐름표 → FCF TTM (회사별, 나눠서 수집)
- `engine/build.py` — 월말(+최근 거래일) 스냅샷 → `site/data/mf.json`
- `site/` — 앱 화면 (순위 계산·백테스트는 폰에서 직접)

## 한계
- DART 주요계정에는 현금·차입금 구분이 없어 기업가치에 부채 전체를 넣었습니다. 현금 많은 회사는 덜 싸게 나옵니다.
- 투하자본에 무형자산·투자자산이 포함돼 자본수익률이 책의 정의(순운전자본+순유형자산)보다 낮게 나옵니다.
- 과거 시가총액도 현재 주식 수로 계산합니다. 유상증자·자사주 소각이 컸던 종목은 과거 순위가 다소 틀릴 수 있습니다.
- 현재 상장 종목만 대상이라 상장폐지 종목이 빠져 있고, 백테스트가 실제보다 좋게 나올 수 있습니다. 싼 종목을 사는 전략이라 이 영향이 큰 편입니다.

검색 결과는 조건 필터링이며 매수 권유가 아닙니다.
